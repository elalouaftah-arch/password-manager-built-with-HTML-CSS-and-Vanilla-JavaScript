## 📌 About The Project

**Password Manager** is a simple and interactive cybersecurity-focused web application designed to help users generate strong passwords and store their credentials securely, right in the browser.

The project was created as part of my programming and cybersecurity learning journey, with a focus on practicing **HTML, CSS, JavaScript, client-side encryption, and security-related concepts**.

---

## ✨ Features

* 🔑 Generate strong, random passwords
* 🎚️ Customize password length and character sets
* 💾 Save and manage stored credentials
* 🔍 Search saved entries quickly
* 🔒 Encrypt stored data locally before saving
* 👁️ Show/hide password fields
* 📋 Copy-to-clipboard functionality
* 🎨 Modern dark-themed interface
* 📱 Fully responsive design
* 🧹 Clear or delete entries easily
* 🚫 No external frameworks
* 🌐 Runs completely in the browser
* 💻 Lightweight and fast
* 🛡️ Designed as a cybersecurity learning project

---

## 🔧 Password Generator Options

The generator lets you customize the strength and composition of each password:

| Option              | Description                          |
| -------------------- | ------------------------------------ |
| Length                | Adjustable, e.g. 8–32 characters     |
| Uppercase Letters     | A–Z                                  |
| Lowercase Letters     | a–z                                  |
| Numbers               | 0–9                                  |
| Symbols               | !@#$%^&* etc.                        |
| Exclude Similar Chars | Avoids ambiguous characters (l, 1, O, 0) |

> **Note:** A strong password typically combines length with a mix of character types. Longer, more varied passwords are significantly harder to crack.

## 💡 How To Use

1. Open the Password Manager application.
2. Set your desired password length and character options.
3. Click **Generate Password**.
4. Copy the generated password or save it with a label (e.g. site name, username).
5. View, search, or delete saved entries at any time.
6. Use strong, unique passwords for every account.

### Example

```text
Options:
Length: 16, Uppercase, Lowercase, Numbers, Symbols

Possible result:

```

## 🔐 Why Use a Password Manager?

Reusing weak or simple passwords across accounts is one of the biggest security risks online. A password manager helps by:

* 🔑 Generating strong, unique passwords for every account
* 🧠 Removing the need to memorize dozens of passwords
* 🔏 Storing credentials in an encrypted format
* 🛡️ Reducing the risk of credential-stuffing attacks
* 🌐 Encouraging better overall password hygiene

## ⚠️ Disclaimer

This project is intended for **educational and cybersecurity learning purposes**.

It is a client-side demonstration project and has **not been professionally audited**. It should not be relied upon as a replacement for established, security-reviewed password managers when protecting sensitive or high-value accounts.

Always use security tools responsibly and keep backups of any important credentials.
